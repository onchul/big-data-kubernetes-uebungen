# Übung 1: Erstellung eines Deployments

**Ziel:** Ein Deployment anlegen und nachvollziehen, auf welchem Knoten ein Pod ausgeführt
wird und wer das entscheidet.

Das Terminal rechts ist mit einem Cluster aus zwei Knoten verbunden.

- Ist eine Aufgabe erledigt, unten rechts auf **Check** klicken.
- **Tipp** und **Lösung** lassen sich in jedem Schritt aufklappen.
- Alle benötigten Befehle stehen auf der Befehlsübersicht an der Wand.

Bearbeitungszeit 12 Minuten, Partnerarbeit zu zweit. `k` ist die Kurzform für `kubectl`,
Tab-Vervollständigung ist aktiv. Unmittelbar nach dem Start braucht das Cluster einige
Sekunden.
